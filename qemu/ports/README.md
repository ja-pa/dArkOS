# Example port launchers

This directory contains the SDLPoP wrapper and adapters used to produce the shared
handheld/QEMU example ZIP. Binaries, data and generated archives are downloaded or
built artifacts, not committed here. Input pins are in
[portmaster.lock.json](../locks/portmaster.lock.json).

See the [PortMaster guide](../docs/PORTMASTER.md) for preparation, installation,
controls, launcher compatibility, sources and validation links. The console test
fixtures remain separate under `qemu/tests/fixtures/`.
